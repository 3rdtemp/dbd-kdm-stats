데이터 반영 방식

시청자 페이지와 스프레드시트가 같은 정보를 사용합니다.

  1. 기존 KDM Record Table의 기록을 자동 조회합니다.
  2. 관리자가 이 화면에서 추가한 기록은 WEB_RECORDS 탭에 저장됩니다.
  3. 저장된 기록은 자동으로 전체 통계에 합산됩니다.
  4. 최대 약 60초마다 새 내용을 다시 읽습니다. 조회 시점에 일시적인 지연이 있을 수 있습니다.
