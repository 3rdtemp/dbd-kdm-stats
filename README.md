# 김덕만 데드 바이 데이라이트 통계 사이트 v1.6.1

기존 v1.5.12를 기준으로 **전체 연도 / 특정 연도**를 사이트 상단에서 바꾸도록 추가했습니다. 연도별 시트는 `2025`, `2026`, `2027` 등 네 자리 이름으로 자동 인식되며, `통합 통계` 탭에는 전체 누적 정보가 표시됩니다.

## GitHub 업로드

기존 저장소 `3rdtemp/dbd-kdm-stats`에 다음 파일을 덮어씁니다.
- `index.html`
- `app.js`
- `styles.css`
- `README.md`

`config.js` 및 기존 초상화 44종, KDM 로고, 슬롯 효과음 파일은 유지합니다. Google Apps Script는 GitHub에서 수정하는 것이 아니라 원본 구글 시트의 **확장 프로그램 → Apps Script**에서 직접 수정해야 합니다.

## Google Apps Script

전체 프로젝트에는 `google-apps-script/Code.gs`(= 별도 `KdmStatsAnnual.gs`)가 포함됩니다. 새 스크립트를 저장한 뒤 원본 구글 스프레드시트에서 `testKdmStats` → `kdmMigrateYearSheetsOnce` → `testKdmStats` → `kdmInstallSummaryTriggers` 순으로 실행합니다. 기존 **KDM Record Table** 탭은 이관 후 삭제 없이 숨깁니다. 기존 배포를 **새 버전**으로 게시하면 `/exec` URL을 그대로 사용할 수 있습니다.

이관 전에는 **파일 → 사본 만들기**로 스프레드시트를 백업하고, 자세한 설명은 제공된 `설치_순서.txt`를 참고하세요.

## 집계 규칙

- 사이트 기본값은 `전체 연도`이며 새로 방문할 때 기본으로 전체 통계를 표시합니다.
- 연도를 선택하면 전체 누적, 승률 그래프, 최근 전적, 살인마 통계, 상세 전적, 생존자 탈출률이 함께 변경됩니다.
- 승률 TOP10은 해당 기간에 **최소 10경기** 기록된 살인마만 대상입니다.
- 신규 `2027` 등의 연도 탭은 Apps Script에서 자동 인식합니다.
- 연도 탭의 기록과 결과만 읽으며, 생존자 맵 이름은 API 결과에 포함되지 않습니다.
- 기존 3칸 룰렛의 4.128초 효과음 및 애니메이션 코드는 변경하지 않았습니다.
