# 김덕만 토토데이 통계 사이트 v1.3 — 조회 전용 / 자동 연동

GitHub Pages 웹사이트 + **기존 구글 스프레드시트 안의 Apps Script** 두 부분으로 구성됩니다. Firebase·Cloudflare·관리자 로그인은 전혀 사용하지 않습니다.

## 이용 흐름

1. 김덕만이 기존 구글 스프레드시트의 `KDM Record Table` 탭에 라운드를 추가합니다.
2. Google Apps Script가 원본을 읽기 전용 처리로 조회하여 **살인마 이름·승패 및 생존자 탈출·사망 결과만** 반환합니다. **생존자 맵 이름은 응답에 포함되지 않습니다.**
3. GitHub Pages 사이트는 방문한 브라우저에서 최초 접속 때 및 5분마다 새 정보를 가져옵니다. 화면이 다시 활성화되면 한 번 더 확인합니다. 스프레드시트 수정 직후 즉시 업데이트되지는 않을 수 있습니다.
4. 사이트 접속자는 어디서도 기록을 수정할 수 없습니다. 원본 시트 공유 권한도 기존 상태 그대로 유지 가능합니다.

## 1. GitHub Pages 파일 업로드

저장소: `https://github.com/3rdtemp/dbd-kdm-stats`

**GitHub 업데이트용 ZIP을 압축 해제**하여 다음 파일을 저장소 최상위에 올립니다:

```text
index.html
app.js
styles.css
config.js
data/records.json
README.md
```

기존 파일이 있는 경우 새 파일로 덮어씁니다. `google-apps-script/Code.gs`는 **GitHub에 배포할 코드가 아니라** 스프레드시트의 Apps Script 에디터에 붙여넣을 내용입니다. 전체 프로젝트 ZIP에 포함되어 있습니다.

GitHub 저장소 **Settings → Pages → Deploy from a branch → main → /(root) → Save**를 설정합니다. 사이트는 다음 주소에서 열릴 예정입니다:

`https://3rdtemp.github.io/dbd-kdm-stats/`

**이 단계까지만으로도 2026-10-17까지의 저장본 582전이 보입니다.** 자동 갱신은 아래 설정을 끝내야 활성화됩니다.

## 2. 구글 스프레드시트에서 Apps Script 설정 (최초 1회)

1. 기존 구글 스프레드시트를 열고 **확장 프로그램 → Apps Script**를 누릅니다.
2. 왼쪽 `Code.gs`의 기존 코드를 비운 후 **전체 프로젝트의 `google-apps-script/Code.gs` 내용 전체**를 붙여넣고 저장합니다. 기존에 다른 Apps Script가 있다면 삭제하지 말고 **새 스크립트 파일**을 만들어 붙여넣습니다.
3. 코드 상단 `SHEET_NAME = 'KDM Record Table'`가 실제 원본 시트 탭 이름과 맞는지 확인합니다. 다르면 정확한 탭 이름으로 수정합니다.
4. 오른쪽 위 **배포 → 새 배포 → 유형 선택 → 웹 앱**을 누릅니다.
5. 다음과 같이 설정합니다:

   - 설명: `DBD 통계 조회 API` (자유롭게 입력)
   - **다음 사용자 인증 정보로 실행:** `나(본인)`
   - **액세스 권한이 있는 사용자:** `모든 사용자` (구글에 로그인하지 않은 방문자도 조회 가능해야 함)

6. **배포**를 누른 뒤 처음 실행 권한을 요청하면 본인 구글 계정으로 승인합니다.
7. 발급된 **웹 앱 URL(`/exec`로 끝나는 주소)**을 복사합니다. `/dev`로 끝나는 시험 URL은 공개 사이트에서 사용할 수 없습니다.
8. 새 브라우저 시크릿 창에서 해당 `/exec` 링크를 열었을 때 `schemaVersion`, `sessions` 등이 포함된 JSON이 보이면 배포가 완료된 것입니다. 최초 실행 시 원본 582경기를 읽어야 합니다. 실시간 환경 검증은 본인 계정에서만 가능합니다.

### 주의할 사항

- Apps Script의 웹 앱 주소는 **공개 통계 조회용**입니다. 외부 방문자도 API 반환 데이터(날짜·승패·살인마 이름)를 볼 수 있습니다. 스크립트에는 쓰기용 함수(`doPost`)나 외부 편집 권한을 넣지 않았습니다.
- **원본 스프레드시트를 '링크가 있는 모든 사용자: 편집자'로 변경할 필요는 없습니다.** Apps Script는 소유자 권한으로 조회하고 외부에는 선별된 데이터만 공개합니다.
- 공개 데이터 전용 스크립트이며, 비밀번호·비밀키·내부 정보가 포함된 스프레드시트에서 사용할 때는 원본 데이터를 반드시 확인해 주세요.
- Google Apps Script의 이용 할당량이 적용됩니다. 대규모 트래픽이 있을 경우 주기를 늘리거나 별도 캐시/서버 방식을 검토해야 합니다.
- Apps Script의 원본을 수정하면 기존 배포를 **배포 관리 → 수정 → 새 버전**으로 다시 게시해야 공개된 웹 앱에 반영됩니다. **스프레드시트의 경기 기록만 수정하는 경우에는 재배포할 필요가 없습니다.**

## 3. 사이트 config.js에 URL 연결

GitHub 저장소에서 `config.js`를 눌러 연필 아이콘(Edit this file)을 선택한 후 아래처럼 변경합니다.

```js
window.KDM_CONFIG = {
  appsScriptUrl: 'https://script.google.com/macros/s/실제-배포-ID/exec'
};
```

**Commit changes** 후 GitHub Pages 재배포가 끝나면 사이트 상단의 상태가 **"Google Sheets 연동 · 자동 갱신"**으로 변경됩니다.

### 확인 절차

- 정상 연동 시: 상단 상태가 초록색, 실제 원본 기록 수와 사이트 경기 수가 동일합니다.
- URL 미설정 시: `저장본 조회 · 연동 설정 전`. 기존 저장본 582경기는 그대로 표시됩니다.
- 권한 설정·URL 오류 시: `연동 오류 · 최근 저장본 표시`. 오류를 고치면 다음 갱신 때 복구됩니다.
- 원본 데이터는 총 **582전(373승·209패)**, 살인마 상대 **548전(353승·195패)**, 생존자 **34전(20탈출·14사망)**입니다.
- 2025-11-08~12-26은 2025년, 2026-01-02부터는 2026년으로 표시합니다.
- 살인마 대전 기록은 체크박스 TRUE/FALSE, 생존자 결과는 `탈출`/`사망`이라는 원본의 규칙을 사용합니다. **체크박스가 아닌 일반 텍스트로 살인마 승패를 기록하기 시작할 경우** 파서의 수정이 필요할 수 있습니다.
- 기존과 다른 살인마 이름이 등장한 경우에도 살인마로 집계하되 분류는 `분류 확인`으로 표시합니다. `Code.gs`의 `KILLER_CATEGORIES`에 등록하면 오리지널/라이선스별 집계에 포함됩니다.

## 보안 요약

- 사이트에는 관리자 로그인, 쓰기 API, 스프레드시트 인증 키/비밀번호가 없습니다.
- 스프레드시트 원본은 비공개로 유지할 수 있으며 Apps Script만 통계용 응답을 공개합니다.
- 공개 JSON에는 생존자 맵 이름이 포함되지 않습니다.
- 기록을 수정할 권한은 **구글 스프레드시트의 기존 편집 권한**에 의해 결정됩니다.
