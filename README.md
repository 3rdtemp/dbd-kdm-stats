# KDM DATA ROOM v1.6.5 — 살인마 목록 자동 연동

## 적용 순서
1. 기존 구글 스프레드시트의 `살인마 목록` 탭(A=이름, B=original/ licensed, C=이미지 파일명)을 유지합니다.
2. 원본 스프레드시트 **확장 프로그램 → Apps Script**에서 `KdmStatsAPI.gs` 내용을 첨부한 `KdmStatsAPI-v4-dynamic-roster.gs` 코드로 교체하고 저장합니다. `매크로.gs`는 유지합니다.
3. 상단에서 `testKdmStats` 실행 → 기존 전적 582전 373승 209패와 `registeredKillers:44` 확인.
4. **배포 → 배포 관리 → 기존 웹 앱 편집 → 새 버전 → 배포**. 기존 웹 앱 URL 유지.
5. GitHub 저장소에 업데이트 ZIP 안의 `app.js`, `index.html`, `styles.css`, `data/records.json`을 상대 경로 그대로 업로드합니다.
6. 사이트에서 강력 새로고침. `Google Sheets 연동 · 자동 갱신` 확인.

## 신규 살인마 등록
- `살인마 목록` 탭 마지막 줄에 새 이름, 분류(original 또는 licensed), 초상화 파일명을 입력합니다.
- 게임 기록이 0전이어도 선택창과 룰렛에 표시합니다. 0전인 캐릭터 승률은 `—`로 표기합니다.
- 초상화가 없다면 C열을 비워 두세요. 사이트에 KDM 로고가 표시됩니다.
- 실제 이미지를 연결하려면 사용 권한이 있는 파일을 `assets/killers/`에 업로드하고 C열에 정확한 파일명을 넣습니다.
- `TR`, 연도별 전적 기록과 기존 수식은 변경하지 않습니다. 단, `TR` 살인마별 누적 통계표에 새 캐릭터 행을 표시하려면 별도로 표/수식 확장이 필요합니다.
- 데이터는 API가 최대 120초 캐시한 뒤 사이트에서 약 5분 간격으로 확인하므로 반영이 즉시는 아닐 수 있습니다.

## 주의
- `.gs`는 GitHub가 아니라 구글 Apps Script 편집기에 붙여넣으세요.
- `config.js`의 웹 앱 URL은 이전과 동일하므로 수정할 필요가 없습니다.
- 신규 살인마 이름은 연도별 기록과 관리용 탭에 동일하게 입력합니다.
- 기존 통계와 3칸 룰렛의 시간·음악은 변경하지 않았습니다.
